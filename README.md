# AI Pózatlasz · Magyar változat

Magyar felület, 288 lefordított póznév és 1439 kameranézet. A „Hogyan
használd?” útmutató bemutatja a póz és a kameranézet kiválasztását, valamint
a referenciakép használatát képgenerátorban. Az oldal kész referenciákat
mutat, nem szerkeszthető ízületi vázat.

A képnézet a teljes képet a rendelkezésre álló területbe illeszti.
A kis nézetképek is az eredeti 3:4 aránnyal, vágás nélkül jelennek meg.
A keresés magyar és eredeti angol nevekkel, ékezet nélkül is működik.

```sh
python3 scripts/build_hu.py
python3 -m http.server 8000
```

Ezután nyisd meg a `http://localhost:8000/` címet. A fordítások a
`scripts/hu-translations.json` fájlban szerkeszthetők. A build a meglévő
angol JSON-ból készít magyar katalógust; nem tölt le képeket.

A képek továbbra is külső forrásból töltődnek. Az eredeti készítő
[felhasználási feltételei](https://ai-pose-gallery.pages.dev/) érvényesek,
beleértve a tömeges képletöltés és újraközlés tilalmát.

# AI Pose Reference Gallery

**Live demo:** https://imorpheuz.github.io/ai-pose-gallery/

A clean, English-language web gallery for browsing **1,439 AI pose reference images** (288 unique poses with multiple angles).

These are faceless gray mannequin line drawings designed as reference for AI image generation (Stable Diffusion, Flux, Midjourney, etc.). Simply use the pose image as a reference and prompt “change to this pose” or use it with ControlNet / IP-Adapter.

## Source

- Original free database by [@giaaibusi](https://x.com/giaaibusi)
- Explicitly released as free, commercial use OK, editing & secondary use OK
- Community mirror & images: [anhao/ai-pose-gallery-zh](https://github.com/anhao/ai-pose-gallery-zh)

## Features

- English port of the [Chinese edition](https://github.com/anhao/ai-pose-gallery-zh) layout (POSE Atlas)
- Series tabs, category and angle filters, group-by-pose or single-image view
- Search by pose name, number, ID or category
- Viewer with angle switching (arrow keys / swipe) and full-size PNG download
- Zero dependencies, responsive

## Local Use / GitHub Pages

1. Clone this repo
2. Serve with any static server (e.g. `python -m http.server`)
3. Or enable GitHub Pages on the `main` branch

The images are loaded from the public community mirror on GitHub so the site works immediately.

## Files

- `index.html` is the gallery app.
- `data/pose-en.json` is the English pose data, generated by `python scripts/build_en.py` from the Japanese source data (translation tables live in that script).
